## ✨ Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de **ampliar a capacidade de criação de websites** com foco em simplicidade e eficiência. A plataforma é ideal para **restaurantes, chefs, blogueiros gastronômicos e entusiastas da culinária** que desejam gerenciar seus próprios sites de forma fácil e intuitiva.

A estrutura do projeto foi pensada para ser limpa e organizada, facilitando a manutenção e a personalização futura.

🔹 Principais destaques:

* ✅ Estrutura de código organizada e escalável (HTML, CSS, JS)
* ✅ Utilização de **Tailwind CSS** para um estilo moderno e rápido de desenvolver
* ✅ Foco na experiência do usuário para uma navegação fluida e intuitiva
* ✅ Design responsivo, adaptável a diferentes dispositivos (desktops, tablets e celulares)
